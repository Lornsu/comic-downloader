# comic.baby 漫画下载器

输入作品 ID 或关键词，选好章节，一键导出「每话 PDF + 全书合集 PDF」的 Windows 桌面工具，
另附一个可直接部署的 PHP 搜索接口。

## 下载即用

**[⬇ 下载 ComicDownloader.exe](ComicDownloader.exe)**（34 MB，单文件，免安装）

Windows 上双击运行，不需要装 Python 或任何依赖。首次启动需等 2~5 秒（解压内置运行时）。

界面从上到下四步：

| 区域 | 操作 |
|---|---|
| **① 搜索作品** | 填作品 ID（如 `350234`）、详情页链接（`https://comic.baby/work/<id>`）或关键词，回车或点「搜索」。关键词命中多部时会弹窗让你挑一本 |
| **② 保存方式** | 选「全部保存」或「自定义保存章节」；选后者会在下方按网格列出全部章节，点格子任意位置勾选（◉ / ○），可一键全选、全不选 |
| **③ 保存路径** | 默认 `<程序目录>/comic/<漫画名>`，可「浏览…」换目录、直接改文本框、或点「默认」还原。勾上「锁定父目录」后路径固定为 `<父目录>/<当前漫画名>`，换作品只换漫画名，设置会记住 |
| **④ 运行日志** | 实时显示每话进度（`5/25 页`）、生成的 PDF 与体积、出错原因 |

## 功能

- **三种查找方式**：关键词、作品 ID、详情页链接
- **章节自选**：整部下载，或逐话勾选
- **图片自动还原**：站点把每页纵向切成多段倒序存储，程序按规则裁切拼回原图，并对拼缝做羽化过渡，避免出现横向错位线
- **双格式输出**：每话一份 PDF，另加一份带章节书签的全书合集
- **可续跑**：已生成的 PDF 自动跳过，中断后重跑不会重复下载
- **实时日志**：进度、体积、错误都直接打在界面上

## PHP 搜索接口

`comic_search.php` 可单独部署到任意 PHP 7.4+（需 curl 扩展）的站点，不需要密钥：

```
/comic_search.php?q=350234&limit=30                 # 列表 + 联想，并发请求后合并
/comic_search.php?q=350234&mode=search              # 只要列表
/comic_search.php?q=斗破&limit=10&page=2&sort=popular
```

返回统一结构，失败时 `data` 为空数组、`msg` 给出原因：

```json
{ "code": 0, "msg": "ok", "data": [ ... ], "meta": { ... } }
```

每条结果都带 `url` 字段，直接是作品详情页地址。

## 输出结构

```
comic/董卓 上+下/
    0001_第1话.pdf          单话 PDF
    0002_下.pdf
    董卓 上+下_合集.pdf      全书合集（带书签）
```

只勾了部分章节时，合集命名为 `<漫画名>_合集_已选N话.pdf`，不会覆盖已有的完整合集。

## 源码

exe 由仓库里的这几个文件构成，依赖见 `requirements.txt`（Python 3.8+）：

| 文件 | 作用 |
|---|---|
| `comic_dl.py` | 下载内核：接口请求、乱序图还原、PDF 生成 |
| `comic_gui.py` | 图形界面 |
| `boot.py` | 程序入口，负责加载上述模块 |
| `build.py` | 生成单文件 exe 的脚本 |

## 常见问题

**杀毒软件报毒**：单文件打包工具常被误判，加白名单即可。

**下载中断**：已完成的 PDF 会保留，重开程序再跑会自动跳过。
